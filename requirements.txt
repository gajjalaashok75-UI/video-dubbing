# pyannote is GATED, exactly like IndicF5: accept the licence on the model page
# and HF_TOKEN in .env covers it. Without it the pipeline runs single-speaker,
# which is what it did before this existed - the stage is never fatal.

#   https://huggingface.co/pyannote/segmentation-3.0

# Set HF_TOKEN to a Hugging Face token whose account has accepted both licences
# above; the diarization stage reports the missing access and continues
# single-speaker rather than failing the render.
#
# Kept out of the default install: it is a heavy optional extra and most videos
# are one speaker. Install with:  pip install "pyannote.audio==3.3.2"
#
# Pinned to 3.3.2 rather than >=3.3.2 on purpose. pyannote 4.x requires

# build the rest of the stack is built against - and CTranslate2 then dies on
# the first encode with "Library libcublas.so.12 is not found or cannot be
# loaded". speaker-diarization-3.1 is the pipeline this project uses.
# pyannote.audio==3.3.2


# ============================================================
# Background preservation
# ============================================================
#
# Demucs splits the original soundtrack into speech and everything else, so the
# film's music, sound effects and ambience survive under the new dialogue
# instead of being replaced by it. Off by default; turn it on per render in the
# studio, or set VIDEOTRANS_PRESERVE_BACKGROUND=1.
#
# Heavy and slow: roughly realtime or worse on CPU, and it downloads a ~300 MB
# checkpoint on first use. Audio is separated in 10-minute chunks so peak memory
# stays bounded on a full-length film.
#
# To enable:  pip install "demucs>=4.0.0"
#
# Colab/Kaggle install demucs==4.0.1 with --no-deps and then name its import
# chain (lameenc, julius, openunmix, dora-search, omegaconf, ...) explicitly,
# so its old dependency tree cannot rewrite Torch, NumPy, Hydra or OmegaConf.
# demucs>=4.0.0
