# Torch stack. The CUDA-12 code line is required, not cosmetic: CTranslate2
# (faster-whisper's backend) is built against CUDA 12 and dlopens
# libcublas.so.12 at the FIRST encode. torch >= 2.7 ships CUDA 13 wheels whose
# cuBLAS is libcublas.so.13, so a hosted image that already had torch 2.11+cu130
# satisfied `torch>=2.2.0` and every render then died ~6s in with
# "RuntimeError: Library libcublas.so.12 is not found or cannot be loaded" -
# after the model had loaded and the job had been accepted.
# 2.6.0 is the last release published for cu124; see the install cell in
# deploy/notebooks/build_notebooks.py, which force-installs that build.
torch>=2.2.0,<2.7
torchaudio>=2.2.0,<2.7
torchvision>=0.17.0,<0.22
