# Mirrors requirements.txt for the image in deploy/docker/Dockerfile, with one
# change: the torch stack is NOT here. The Dockerfile installs torch, torchaudio
# and torchvision from the cu124 index in their own layer, so this file must not
# name them or pip would pull the CPU-only wheels from PyPI instead. That layer
# pins 2.6.0: it is the last cu124 build, and CTranslate2 needs libcublas.so.12
# (CUDA 12), which the CUDA 13 wheels that torch >= 2.7 ships do not provide.
#
# Build context is the repository root; this file is copied to /app/requirements.txt.
